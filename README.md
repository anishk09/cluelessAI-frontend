# CluelessAI Frontend

Multi-Modal Wardrobe Intelligence & Social Trend Recommendation Engine.

## Stack
- **Framework**: React 18 with TypeScript & Vite
- **Styling**: Tailwind CSS
- **Cloud Ingest**: Direct S3 Presigned URL Uploads
- **Telemetry**: Local meteorological data injection & social vector scoring

## Architecture Highlights
- Isolated DynamoDB partition integration for wardrobe records
- Foreground clothing segmentation pipeline
- Context-aware scoring against ambient weather APIs and TikTok/Pinterest aesthetic vectors
